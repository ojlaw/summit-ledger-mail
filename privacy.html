Privacy policy

Summit Ledger Mail · last updated November 17, 2026

Summit Ledger Mail is a private tool used only by its owner, on the owner's own Gmail accounts. It is not offered to the public.

What data it reads

With the account owner's permission, the tool uses the Gmail API with read-only access (gmail.readonly) to read email messages such as order confirmations, shipping notices and receipts.

How the data is used

Email content is used only to match purchases, shipments and refunds to the owner's bookkeeping ledger. It is not used for advertising, and it is not used to train general AI or machine learning models.

Where the data is kept

Data read from Gmail stays on the owner's own computer and in the owner's own Google account. Sign-in tokens are kept in the computer's secure keychain.

Sharing

Data read from Gmail is not sold, and is not transferred to anyone else, except where the law requires it.

Google API Services User Data Policy

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the tool's local files removes the data it has kept.
